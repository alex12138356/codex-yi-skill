# 协作协议

> 各线之间的协作规范。适用于所有对话线。

## 1. 回传机制

- 各线完成重要阶段后，写入 回传日志.md
- 中枢定期读取回传日志，了解各线进展
- 回传格式：一句话 + 文件路径
- 不需要报每一个操作细节

## 2. 文件共享

- 共享知识库.md 放桌面，所有对话公用
- 各线自己的文件放各自项目目录
- 项目细节不在知识库中全文写入，只用一行文件路径引用

## 3. SESSION_LOG 机制

- 每个对话快接近 400 上限时，把状态总结到 SESSION_LOG
- 新对话启动后先读 SESSION_LOG，再读共享知识库
- SESSION_LOG 放项目目录，不是桌面

## 4. 新对话启动流程

1. 中枢决定开新线
2. 复制启动指令.txt 到新对话任务描述
3. 新对话启动后先读共享知识库
4. 开始执行，完成回传
